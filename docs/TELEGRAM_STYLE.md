# سبک پست‌ها و استفاده از امکانات تلگرام

## ۱) قالب‌بندی (HTML تلگرام)
| امکان | چه کاری می‌کند | کجا استفاده کنیم |
|---|---|---|
| **توپر** `<b>` | عنوان و کلمهٔ کلیدی | عنوان هر پست، یک یا دو کلمه در متن |
| **نقل‌قول** `<blockquote>` | یک بلوک جدا و کم‌رنگ | «نکتهٔ امروز»، خلاصه، جملهٔ مهم، هشدار |
| **نقل‌قول بازشونده** `<blockquote expandable>` | بعد از ۳ خط جمع می‌شود | جزئیات یا قدم‌های بلند که همه نمی‌خواهند ببینند |
| اسپویلر `<tg-spoiler>` | تا لمس نشود پنهان است | کد تخفیف، جواب نظرسنجی (حس کنجکاوی)؛ کم |
| `<code>` | با لمس کپی می‌شود | کد تخفیف، نام سرور، دستور |
| لینک `<a href>` | لینک داخل متن | آموزش کامل، لینک به پست دیگر، لینک به ربات |
| ایموجی سفارشی | ایموجی برند | فقط وقتی ربات پشتیبانی دارد (موتور آماده است) |
| `disable_notification` | پیام بی‌صدا | نبض، پست‌های معمولی؛ فقط خبر واقعی با صدا |

در کد: `serverless-bot/tgcloud/lib/tgfmt.js` (`b`, `quote`, `expandable`, `link`, `tags`, `postLink`, `fmtMsg`). هر ورودی escape می‌شود؛ اگر تلگرام قالب را نپذیرد (نسخهٔ قدیمی)، **همان پیام به‌صورت متن ساده دوباره ارسال می‌شود** و هرگز پیام از دست نمی‌رود. نبض روزانه همین‌الان آموزش را در نقل‌قول می‌فرستد.

## ۲) جدول
تلگرام **جدول واقعی ندارد.** گزینه‌ها:
- **داده کم (۳ تا ۵ ردیف):** فهرست با عنوان توپر، مثلاً `<b>نقره</b> ۲۰٪ · ≥ ۵۰۰ گیگ`. در متن راست‌به‌چپ بهتر از ستون‌بندی است.
- **داده زیاد یا مقایسه:** **صفحهٔ Telegraph** (با جدول و عکس، Instant View می‌شود) و در پست یک لینک «مقالهٔ کامل» با خلاصهٔ ۳ خطی. می‌توانم `telegraph.js` بسازم تا خودکار ساخته شود.
- **قیمت‌ها:** بنر تصویری (همان سیستم Signal) تا جدولِ خراب راست‌به‌چپ پیش نیاید.
- `<pre>` فقط برای اعداد و کد انگلیسی؛ برای فارسی ترازش به هم می‌ریزد.

## ۳) لینک‌های داخلی و ناوبری سریع
1. **لینک به پست:** `https://t.me/<کانال>/<شماره>`. ربات هنگام انتشار شمارهٔ پیام را نگه می‌دارد.
2. **پست فهرست سنجاق‌شده:** «فهرست پیچا» با بخش‌ها (آموزش اتصال، امنیت، وضعیت، پرسش‌ها) و لینک هر پست. ربات خودش با `editMessageText` به‌روزش می‌کند.
3. **پست‌های سری:** زیر هر پست دکمه‌های `‹ قبلی` و `بعدی ›` (لینک به پست‌های همان سری)، و در متن «بخش ۲ از ۴» با لینک به فهرست.
4. **لینک عمیق ربات:** `?start=...` (خرید، تست، پشتیبانی، `fit`) و مینی‌اپ `?startapp=` برای صفحات پنل.
5. **هشتگ‌ها** (پایین) برای ناوبری بین پست‌ها.
6. نقل‌قول و جدول لینک ندارند؛ برای رفتن به یک جای مشخص، لینک به **پست** یا به **صفحهٔ Telegraph** با لنگر (`#عنوان`) می‌گذاریم.

## ۴) هشتگ: به درد می‌خورد؟
**بله، ولی برای ناوبری، نه برای دیده‌شدن.** تلگرام الگوریتم کشف با هشتگ ندارد؛ با لمس هشتگ فقط همان پست‌های **همان کانال** فهرست می‌شود. پس:
- **خوب است برای آرشیو:** کسی «آموزش اتصال» را می‌خواهد، `#آموزش_اتصال` را می‌زند و همه را می‌بیند.
- **خوب است برای کمپین و رهگیری:** `#جمعه_سیاه_۱۴۰۵`.
- **«خز» می‌شود اگر زیاد باشد.** ۱ تا ۳ هشتگ، همیشه آخر پست و در یک خط؛ هرگز ۱۰ تا.
- **در پیام خصوصی (ربات) بی‌فایده است**؛ فقط در کانال.
- فارسی: کلمه‌های چندبخشی با زیرخط (`#آموزش_اتصال`)؛ نیم‌فاصله و علامت نگارشی نه. از همان فهرست ثابت استفاده کنیم تا هشتگ تکراری با املای دیگر نسازیم.
**فهرست ثابت:** `#آموزش` `#اتصال` `#وضعیت` `#امنیت` `#پرسش_و_پاسخ` `#پیشنهاد` `#خبر` `#تجربه_مشتری` `#نمایندگان` `#مناسبت`.

## ۵) قالب‌های آماده
**وضعیت/اطلاعیه**
```
<b>وضعیت امروز</b>
همه سرورها پاسخ می‌دهند.
<blockquote>اگر کند بود: اشتراک را به‌روزرسانی کنید و روی سرورها «تست پینگ» بزنید.</blockquote>
#وضعیت #اتصال
[💬 پشتیبانی] [🟢 وضعیت سرورها]
```
**آموزش**
```
<b>اتصال در ۲ دقیقه</b>
یک خط دربارهٔ مشکل.
<blockquote>خلاصه: برنامه را نصب کنید، لینک را وارد کنید، تست پینگ بزنید.</blockquote>
<blockquote expandable>قدم ۱ … قدم ۲ … قدم ۳ …</blockquote>
<a href="…">مقالهٔ کامل (Telegraph)</a>
#آموزش #اتصال
[🎁 تست رایگان] [📚 آموزش کامل] [💬 پشتیبانی]
```
**پیشنهاد واقعی**
```
<b>جمعهٔ سیاه پیچا</b>
۲۰٪ تخفیف با کد <code>{کد}</code> تا امشب ۲۳:۵۹.
#پیشنهاد #جمعه_سیاه_۱۴۰۵
[🛒 خرید اشتراک] [📋 کپی کد] [🎁 تست رایگان]
```
**رادار (خبر + راه‌حل)**
```
<b>{مشکل روز}</b>
یک جمله: چه شده و چه کسی را اذیت می‌کند.
<blockquote>راه‌حل: …</blockquote>
<a href="…">منبع</a>
#خبر #آموزش
[🎁 تست رایگان] [🛒 خرید] [📤 بفرست]
```
قاعده: عنوان توپر، حداکثر ۴ خط متن، ۱ نقل‌قول، ۱ بازشونده، ۱ لینک، ۱–۳ هشتگ، ۲–۴ دکمه.

## ۶) امکانات دیگر تلگرام که باید روشن شوند
| امکان | کار | وضعیت |
|---|---|---|
| **واکنش‌ها** | در تنظیمات کانال چند واکنش (👍 🔥 ❤️ 🙏) فعال کنید؛ بدون ساخت چیزی، نظر سریع و آمار می‌دهد | شما، ۱ دقیقه |
| **نظرات (گروه بحث)** | گروه بحث وصل کنید؛ پرسش‌ها همان‌جا جواب داده می‌شود (مشتری بدون ربات هم می‌پرسد) | تصمیم شما |
| **سنجاق** | پست فهرست و پست وضعیت | ربات می‌تواند |
| **نظرسنجی و کوییز** | «کدام سرور؟» و کوییز آموزش اتصال (با جواب درست) | قابل ساخت در پست‌بات |
| **پست بی‌صدا** | هر پست عادی بی‌صدا، فقط اطلاعیهٔ واقعی با صدا | آماده |
| **پیش‌نمایش لینک** | کنترل بزرگ/کوچک/بدون پیش‌نمایش برای هر پست | قابل ساخت |
| **دکمهٔ کپی** | `📋 کپی کد`، شمارهٔ کارت (`copy_text`) | آماده در ربات |
| **دکمهٔ اشتراک** | `📤 به دوستت بفرست` (لینک `t.me/share/url`) | آماده |
| **زمان‌بندی** | پست‌بات منتشر می‌کند (cron)؛ زمان‌بندی داخلی تلگرام را هم ادمین می‌تواند در اپ استفاده کند | پست‌بات |
| استوری کانال | فقط از اپ و با اکانت ادمین؛ بنر استوری ۱۰۸۰×۱۹۲۰ را می‌سازم | دستی |
| ایموجی سفارشی | برند پیچا؛ ربات پشتیبانی دارد | بسته به اکانت |
