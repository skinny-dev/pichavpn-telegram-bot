# احیای کانال (۱۳هزار عضو، تعامل کم)

هدف دوم محتوا: دیده شدن. فرضیه‌ها (باید اندازه‌گیری شوند، نه باور):
1. بخشی از ۱۳هزار نفر فقط برای عضویت اجباری ربات آمده‌اند و کانال را بی‌صدا کرده‌اند.
2. کانال‌های دیگرشان شلوغ است و پست‌های ما «شبیه بقیه» است.
3. تا حالا دلیلی نبوده که کانال را از حالت بی‌صدا دربیاورند.

## ۱. اول اندازه بگیریم (۳ عدد)
- **نرخ دیده‌شدن** = میانگین بازدید ۲۰ پست آخر ÷ تعداد اعضا. زیر ~۵٪ یعنی کانال عملاً خاموش است.
- **ورود از کانال به ربات** = چند نفر از لینک‌های پست‌ها `/start` می‌زنند (لینک ردیابی‌شده برای هر پست).
- **رشد/ریزش روزانه** = `getChatMemberCount` هر روز.
(بازدید پست‌ها را از آمار کانال تلگرام بردارید؛ API ربات بازدید نمی‌دهد.)

## ۲. اصل: ربات دارایی ماست، کانال اجاره‌ای
پیام ربات به کسی که کانال را بی‌صدا کرده هم می‌رسد (تا وقتی ربات را بلاک نکرده). پس هدف اصلی کانال: **تبدیل دنبال‌کننده به کاربر ربات**، نه فقط بازدید.

## ۳. چطور دوباره دیده شویم
- **کم‌تر ولی ضروری:** روزی ۱ پست باارزش. بی‌صدا نکردن را با ارزش بگیریم، نه با تعداد.
- **عادت ثابت:** یک ساعت ثابت («وضعیت اتصال امروز») که مردم منتظرش باشند.
- **پست‌هایی که فقط ما داریم:** وضعیت واقعی شبکه، کدام سرور امروز بهتر است، راه‌حل مشکل روز. (اینجا داده‌ٔ زندهٔ پنل مزیت ماست.)
- **تعامل سبک:** نظرسنجی «امروز اتصالتان چطور است؟»، واکنش‌ها؛ این‌ها اعضا را فعال می‌کند و الگوریتم تلگرام را هم کمک می‌کند.
- **اعلان فقط برای مهم:** پست بی‌صدا برای محتوای عادی، با اعلان فقط برای خبر واقعی (قطعی/اصلاح/اطلاعیه) تا اعتماد به اعلان‌ها برگردد.
- **دعوت به ربات:** هدیه یا امتیاز واقعی برای `/start` (نه قرعه‌کشی بی‌پایان).
- **استوری کانال** برای دیده‌شدن در فهرست.

## ۴. برنامهٔ ۱۴روزهٔ «بیداری»
۳ روز اندازه‌گیری ← ۷ روز «وضعیت امروز + ۱ آموزش/حل‌مشکل» با ساعت ثابت و نظرسنجی ← ۴ روز مقایسه (نرخ دیده‌شدن، /start از کانال) و تصمیم.

## ۵. سؤالات باز
- آیا عضویت اجباری کانال برای استفاده از ربات روشن است؟ (روی نتیجهٔ اندازه‌گیری و پاک‌سازی تأثیر دارد.)
- اعضا از چه راهی آمده‌اند (تبلیغ، ربات، دعوت)؟

## ۶. اندازه‌گیری اول (۱۲ پست اخیر)
بازدیدها: 612، 793، 1011، 1212، 1464، 3827، 2948، 2633، 2356، 1983، 1514، 1400.
- میانگین ≈ **۱٬۸۱۳**، میانه ≈ **۱٬۴۸۹**، بیشینه ۳٬۸۲۷، کمینه ۶۱۲.
- نرخ دیده‌شدن (۱۳هزار عضو): میانگین ≈ **۱۴٪**، میانه ≈ ۱۱٪. **کانال مرده نیست**؛ تقریباً ۱٫۵ تا ۲هزار نفر واقعاً می‌بینند.
- پست‌های ۳٬۸۲۷ / ۲٬۹۴۸ / ۲٬۶۳۳ دو تا سه برابر میانه‌اند؛ باید بدانیم موضوعشان چه بود.
- (کم‌بودن ۶۱۲ و ۷۹۳ ممکن است فقط به‌خاطر جدید بودنشان باشد؛ بازدید یک پست تا ۲۴–۴۸ ساعت بالا می‌رود.)
