# اتصال Paychi به ربات (درگاه کارت‌به‌کارت خودکار، کنار Variza)

Paychi **اضافه** می‌شود؛ Variza دست نمی‌خورد. دکمهٔ «💳 کارت به کارت (پی‌چی)» فقط وقتی به مشتری نشان داده می‌شود که Paychi روشن و کلیدش ثبت باشد.

## ۱. سمت سرور 🟥 (Paychi)
1. Paychi باید روی یک آدرس **HTTPS با پورت 443** در دسترس باشد (ربات سرورلس فقط 80/443 را باز می‌کند). مثلاً `https://paychi.theownlypwcha.top` با Apache/Nginx reverse proxy. رکورد DNS را «DNS only» (خاکستری) بگذارید.
2. در داشبورد Paychi: فروشگاه (merchant) بسازید، کارت‌ها را اضافه و اپ اندروید (listener پیامک) را جفت کنید، سپس یک **API key** (`pk_…`) بسازید.
3. اگر وب‌هوک امضادار می‌خواهید، secret وب‌هوک را هم از داشبورد بردارید (اختیاری؛ وب‌هوک فقط «اشاره» است و پول همیشه با inquiry تأیید می‌شود).

## ۲. ریلهٔ پرداخت 🟥 (یک‌بار، چون مسیر `/paychi` اضافه شد)
```
scp -r pasarguard/pay_relay root@168.222.43.253:/root/
ssh root@168.222.43.253 'bash /root/pay_relay/install.sh pay.theownlypwcha.top'
```
(کلید فعلی ریله حفظ می‌شود.)

## ۳. دیپلوی ربات
```
bash scripts/deploy.sh && php scripts/serverless_setup.php project --main --full \
  && cd /root/picha-serverless-main && npx tgcloud push && npx tgcloud run endpoints/admin_diag '{}'
```

## ۴. ثبت کلید (بدون نمایش در چت)
```
cd serverless-bot && node tools/setpay.mjs paychi
```
آدرس پایه، API key و (اختیاری) webhook secret را با ورودی مخفی می‌پرسد و Paychi را روشن می‌کند. وضعیت: `node tools/setpay.mjs status`.

## ۵. تست
یک شارژ کوچک (مثلاً ۲۰٬۰۰۰ تومان) با دکمهٔ پی‌چی. مبلغ دقیق ریالی (یکتا) نمایش داده می‌شود؛ همان را واریز کنید. باید خودکار شارژ شود؛ اگر وب‌هوک نرسید، دکمهٔ «پرداخت کردم» یا کران تطبیق (هر ۳۰ ثانیه، فقط سفارش‌های ۶۵ دقیقهٔ اخیر) آن را می‌گیرد.

## امنیت و رفتار
- مبلغ تومان × ۱۰ = ریال. پول فقط وقتی ثبت می‌شود که inquiry با کلید ما بگوید `paid`، `order_id` همان سفارش ما باشد و مبلغ کمتر از صورت‌حساب نباشد.
- ثبت پرداخت با یک claim اتمیک انجام می‌شود؛ تکرار وب‌هوک/دکمه چیزی دوباره شارژ نمی‌کند.
- خطای Paychi (محدودیت کارت، نبود کارت فعال، قطعی، کلید اشتباه) → دکمه ۱۰ تا ۳۰ دقیقه پنهان می‌شود و مشتری روش‌های دیگر را می‌بیند.

## روشن/خاموش از داخل ربات
در کیبورد ادمین دکمهٔ «💳 درگاه‌های کارت به کارت» (یا دستور /gateways) پی‌چی و واریزا را با یک دکمه روشن/خاموش می‌کند.

## اگر کار کرد و خواستید Variza خاموش شود
`node tools/setpay.mjs variza off` (برگشت: `variza on`).
