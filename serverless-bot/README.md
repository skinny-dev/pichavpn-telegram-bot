# Picha — full bot on Telegram Serverless (in progress)

The whole bot in JavaScript on Telegram Serverless, replacing the PHP bot on the server.
Tables and columns have the same names as the PHP bot's MySQL database (`tgcloud/schema.js`,
generated by `php scripts/serverless_schema.php`), so data moves over as it is.

Local tests (no Telegram needed): `node --no-warnings --import ./test/register.mjs test/<file>.mjs`
— `test/sdk/` stands in for the Serverless SDK (SQLite via node:sqlite, recorded Bot API calls).
