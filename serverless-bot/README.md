# Picha — the whole bot on Telegram Serverless

The Picha bot (customer side, admin side, payments, cron, Mini App admin panel) in JavaScript on Telegram Serverless,
replacing the PHP bot (`index.php`, MySQL) on the bot server. Tables and columns keep the PHP bot's names
(`tgcloud/schema.js`, generated by `php scripts/serverless_schema.php`), so data moves over as it is.

**Going live: [CUTOVER.md](CUTOVER.md)** (Persian, step by step, with the rollback).

## Layout
```
tgcloud/handlers/      one file per update kind → lib/mode.js (relay | native | maint)
tgcloud/lib/bot.js     index.php: context, customer routes (lib/routes/*), admin routes (lib/admin/*), relay pull, lazy cron
tgcloud/lib/panelapi/  dashboard/api.php: the panel's JSON API (tables, stats, support, payments, manual orders, referrals,
                       promotions, order/customer management, finance/*)  — one endpoint: tgcloud/endpoints/panel.js
tgcloud/lib/cron.js    cronbot/*.php without a cron: one due job per incoming update
tgcloud/lib/relay.js   pulls Variza / bank-SMS events from the payment relay (../pasarguard/pay_relay) and pays them
tgcloud/endpoints/     panel.js (the Mini App talks to it) · admin_import.js (CLI only)
dist/                  the admin panel (../dashboard-src) built for Serverless; tgcloud.jsonc serves it as the Mini App
tools/import.mjs       MySQL export → Serverless database (--cold / --hot)
```

## Tests (no Telegram, no Serverless needed)
`test/sdk/` stands in for the Serverless SDK (SQLite via `node:sqlite`, recorded Bot API calls).
```bash
node --no-warnings --import ./test/register.mjs test/<file>.mjs <export dir>     # relay_test, cron_test, broadcast_test, mode_test …
```
**Differential tests** — the same updates go to the PHP bot (MySQL, a fake Telegram) and to this bot; every Bot API call is compared:
```bash
PHP_ROOT=/path/to/php-copy DIFF_DIR=/tmp/diff bash test/diff/all.sh          # 14 scenarios
PHP_ROOT=… PANEL_EXPORT=/tmp/pexport bash test/panel/run.sh cases/*.mjs       # the panel API: PHP api.php vs tgcloud/lib/panelapi
node --no-warnings --import ./test/register.mjs test/panel/ui_smoke.mjs <export dir>   # the real panel in a browser over the Serverless transport
```

## Deploy
```bash
npm run deploy        # builds the panel into dist/ and `tgcloud push`
```
