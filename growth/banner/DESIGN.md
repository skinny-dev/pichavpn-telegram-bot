# سیستم طراحی بنرها — «Signal» (نسخه ۲، هم‌زبان با پنل)

بنرها همان زبان بصری پنل مدیریت را دارند (`dashboard-src/src/index.css`): سطح تاریک سرد، حاشیه‌ی ظریف ۱ پیکسلی، گوشه‌ی بریده، **یک رنگ تأکید**، بدون سایه و درخشش. هدف: جدی و تمیز، نه «اسلاپ» (هاله، گرادیان رنگارنگ، شیشه‌ای، ذرات).

## ساختار ثابت
- زمینه #080b11 با شبکه‌ی ۴۰ پیکسلی خیلی کم‌رنگ (همان پنل).
- قاب اصلی با دو گوشه‌ی بریده (بالا-چپ و پایین-راست).
- سمت چپ: سلول بزرگ نماد (خط ظریف، رنگ تأکید) + تا ۳ سلول کوچک نماد؛ یک خط کوتاه رنگ تأکید بالای سلول بزرگ.
- سمت راست: لوگو + نام، برچسب فنی لاتین (مونو)، عنوان با یک کلمه‌ی رنگی، زیرعنوان خاکستری، نشان‌ها، دکمه‌ی عمل (گوشه‌ی بریده) و هندل ربات.

## رنگ تأکید به‌ازای دسته (`theme`)
| دسته | رنگ |
|---|---|
| جذب، محصول، تست رایگان | `cyan` |
| آموزش، راهنما | `green` |
| مناسبت و تخفیف | `amber` |
| رفرال و تعامل | `pink` |
| امنیت، هشدار، قطعی | `red` |
| خبر، تحلیل، اطلاع‌رسانی | `violet` |

## قاعده‌ها
- نماد از Lucide یا هم‌سبک آن (`icons/`)؛ خطی هم‌وزن. هیچ نماد سه‌بعدی یا ایموجی.
- عنوان ۲ تا ۵ کلمه؛ یک کلمه‌ی کلیدی با `[[کلمه]]` رنگ می‌گیرد.
- هر کلمه از متن تأییدشده می‌آید؛ بنر ادعایی اضافه نمی‌کند (سرعت، آپ‌تایم، تعداد کاربر فقط با عدد واقعی).
- فونت: **یکان‌بخ** به‌محض اینکه فایل‌هایش در `../brand/fonts/` (با نام شامل `yekan` و وزن مثل `Bold`) بیاید خودکار استفاده می‌شود؛ تا آن موقع Vazirmatn. برچسب‌های لاتین: JetBrains Mono.
