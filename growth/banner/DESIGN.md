# سیستم طراحی بنرها — «Signal»

حس: پنل فرمان/ترمینال تاریک؛ فنی، تمیز، قابل‌اعتماد. همه‌ی بنرها یک قالب دارند و فقط رنگ، نماد و متن عوض می‌شود.

| دسته | رنگ (`theme`) | نمونه‌ی نماد |
|---|---|---|
| جذب، محصول، تست رایگان | `cyan` #22d3ee | gift, rocket, zap, server |
| آموزش، راهنما، خبر خوب | `green` #4ade80 | smartphone, laptop, download, book-open |
| مناسبت و تخفیف | `amber` #fbbf24 | watermelon, pomegranate, moon, flame, star, party-popper |
| رفرال و تعامل | `pink` #f472b6 | handshake, user-plus, gift |
| امنیت، هشدار، قطعی | `red` #fb7185 | shield-check, lock, siren, fingerprint |
| خبر، تحلیل، اطلاع‌رسانی | `violet` #a78bfa | wrench, hourglass, bar-chart-3, radar |

قواعد:
- زمینه #05080d، شبکه‌ی ریز، خط‌های اسکن، قاب با ۴ گوشه؛ هیچ عکس یا نماد سه‌بعدی نمی‌آید (فقط خطی هم‌وزن).
- یک نماد اصلی بزرگ در قاب شش‌ضلعی + حداکثر ۳ نماد کوچک روی حلقه. همه از Lucide یا هم‌سبک آن (`icons/`).
- عنوان ۲ تا ۵ کلمه؛ یک کلمه‌ی کلیدی با `[[کلمه]]` رنگ نئون می‌گیرد.
- برچسب فنی لاتین (`tag`) فقط برای حس فنی، نه ادعا. برچسب‌های فارسی داخل `[ ]`.
- هر کلمه از متن تأییدشده می‌آید؛ بنر هیچ ادعایی اضافه نمی‌کند (سرعت، آپ‌تایم، تعداد کاربر فقط با عدد واقعی).
- یک دکمه‌ی عمل (CTA) با رنگ دسته؛ هندل ربات پایین.
