# متن‌های آمادهٔ پنل همکاری (برای بازاریاب)

لحن: همان لحن پیچا (محاوره‌ای و صمیمی، «درود» نه «سلام»؛ بدون ادعای بزرگ). همهٔ متن‌ها فقط چیزهایی را می‌گویند که همین حالا در ربات کار می‌کند.
آیدی ربات: `@pichanet_bot` · پشتیبانی: `@pichavpn_support`

## قبل از ارسال، این‌ها را چک کن (مسئول: مالک)
- [ ] «پله‌ی خودکار» روی حالت **زنده** است (وگرنه تخفیف را دستی بدهید و جملهٔ «خودکار» را حذف کنید).
- [ ] اعداد جدول نمونه با لیست قیمت امروز می‌خواند (نمونه‌ها از لیست فعلی‌اند).
- [ ] اگر جملهٔ «نام کاربری با اسم خودت» را می‌گویی: «نام برند» در پنل روشن باشد (از سطح ۱۵٪ به بالا).
- [ ] اگر جملهٔ «اول از همه خبردار میشی» را می‌گویی: اطلاع‌رسانی به همکاران روی زنده باشد.

## قوانین بازاریاب (کوتاه)
1. **عدد سود قول نده.** فقط درصد تخفیف پله‌ای (۱۰٪ تا ۳۰٪) و جدول نمونه. «فلان‌قدر درآمد» نگو.
2. **بدون فوریت ساختگی** («فقط تا امشب»، «ظرفیت تکمیل» ممنوع).
3. اگه کسی گفت «تماس نگیرید / پیام نده»، همان لحظه حذفش کن و دیگه پیام نده.
4. شمارهٔ لیست و اطلاعات مغازه‌ها جایی عمومی نره.
5. چیزی که رقیب‌ها می‌گویند و ما نمی‌توانیم ثابت کنیم را نگو (آخر همین فایل).

## ۱) پیام همگانی / کانال (سبک «لیست» مثل رقیب، ولی با ادعای واقعی)

**نسخهٔ الف (لیست‌وار):**
```
‼️ پنل همکاری پیچا باز شد

🔵 شروع با کیف پول؛ هر فروش از موجودی کم میشه
🔵 تخفیف پله‌ای: از ۱۰٪ شروع، با حجم بیشتر تا ۳۰٪ زیر لیست
🔵 ساخت سرویس تکی و دسته‌ای از همین ربات
🔵 مشتری‌هات رو ببین، تمدیدشون کن، گزارش خریدت رو داشته باش
🔵 پشتیبانی ویژه برای همکارها
🔵 لوکیشن‌های متنوع: آمریکا، آلمان، هلند، لهستان، فنلاند
🔵 تست رایگان بگیر و خودت امتحان کن

📌 ثبت درخواست همکاری: @pichanet_bot (دکمهٔ «درخواست نمایندگی»)
💬 پشتیبانی: @pichavpn_support
```
دکمهٔ زیر پست: «درخواست همکاری» (لینک ربات) · «تست رایگان».

**نسخهٔ ب (کوتاه، با جدول)** ــ این یکی برای استودیو/کانال است (قالب HTML)؛ در چت معمولی به‌جای `<pre>` همان ردیف‌ها را ساده بنویس:
```
💼 اگه به مشتری‌هات VPN میدی، پنل همکاری برای توئه

<pre>سطح      │ تخفیف از لیست
شروع      │ ۱۰٪
برنز      │ ۱۵٪
نقره      │ ۲۰٪
طلا       │ ۲۵٪
پلاتین    │ ۳۰٪</pre>

هر چی بیشتر بخری، ارزون‌تر میگیری. شروعش با تست رایگان و یه شارژ کوچیکه.
@pichanet_bot · @pichavpn_support
```
(حجم هر سطح: ۰ / ۱۰۰ / ۵۰۰ / ۲٬۰۴۸ / ۵٬۱۲۰ گیگ در ۳۰ روز.)

## ۲) پیام اول به مغازه‌دار / فروشنده (چت یا تلگرام)

**عمومی:**
```
درود، وقتتون بخیر 🌿
من [نام] هستم از پیچا. سرویس VPN پایدار با ربات تلگرام داریم و یه پنل همکاری هم برای کسایی که VPN به مشتریاشون میدن.
از ۱۰٪ زیر قیمت لیست شروع میشه و با خرید بیشتر تا ۳۰٪ میره. اگه دوست داشتید اول یه تست رایگان بفرستم خودتون کیفیتش رو ببینید؟
```

**برای موبایل‌فروشی:**
```
درود، وقتتون بخیر 🌿
مشتری که گوشی میخره یا تعمیر میکنه، معمولا همون لحظه VPN هم میخواد. ما یه پنل همکاری داریم که شما همون‌جا سرویس بدید و خودتون قیمت فروش رو بذارید؛ نصب و راهنمای اتصال هم آماده‌ست.
تخفیف از ۱۰٪ شروع میشه و با حجم خریدتون بیشتر میشه. یه تست رایگان براتون بفرستم؟
```

**برای کانال‌دار / ادمین گروه:**
```
درود 🌿
مخاطب آماده دارید و بعضی‌هاشون VPN میخوان. با پنل همکاری پیچا میتونید اشتراک بفروشید؛ تخفیف پله‌ای از ۱۰٪ تا ۳۰٪، مشتری‌هاتون رو هم از همون ربات می‌بینید و تمدید می‌کنید.
اگه علاقه داشتید، تست رایگان بدم خودتون امتحان کنید؟
```

## ۳) بعد از تست رایگان (پیگیری)

**۲۴ ساعت بعد:**
```
درود 🌿 تست رو امتحان کردید؟ اگه سوالی بود یا جایی گیر کردید همین‌جا بنویسید، کمک میکنم.
```

**۳ روز بعد (اگه جواب نداد، فقط یک بار):**
```
درود، فقط یه یادآوری کوچیک بود. اگه تست خوب بود و دوست داشتید همکاری رو شروع کنیم، دکمهٔ «درخواست نمایندگی» تو ربات هست. اگه هم الان وقتش نیست، مشکلی نیست. سپاسگزارم 🌿
```

## ۴) جواب به اعتراض‌ها

| می‌گه | بگو |
|---|---|
| «چقدره؟» | «تخفیف پله‌ایه: از ۱۰٪ زیر لیست شروع میشه و با خرید بیشتر تا ۳۰٪ میره. مثلا (از لیست امروز) یه پلن ۴۰ گیگی ۲۰۰ هزار تومانیه؛ شما ۱۸۰ هزار تا ۱۴۰ هزار میگیرید.» (عدد رو با لیست روز چک کن.) |
| «اگه نفروختم؟» | «سرمایهٔ اولیه فقط یه شارژ کوچیک کیف پوله و هر فروش از همون کم میشه. دیر یا زود فروختید، چیزی انبار نمیشه.» |
| «کیفیتش خوبه؟» | «پیشنهادم اینه تست رایگان بگیرید و خودتون امتحان کنید. لوکیشن مناسب هر کار هم تو ربات با دکمهٔ «بهترین سرور» هست.» |
| «پشتیبانی دارید؟» | «بله، پیام همکارها با اولویت بررسی میشه.» |
| «قطع بشه چی؟» | «حق دارید نگران باشید. وضعیت و قطعی‌ها رو شفاف اطلاع میدیم و همکارها زودتر خبردار میشن. اگه مشکلی شد با پشتیبانی هماهنگ میکنیم.» (فقط اگه اطلاع‌رسانی زنده‌ست.) |
| «رقیب ارزون‌تره / تحویل سریع‌تره» | «مقایسه‌ی عادلانه‌ش اینه که ببینید کدوم رو مشتری‌تون راضی‌تره. ما تست رایگان میدیم؛ امتحان کنید و خودتون ببینید.» |
| «بعدا» | «حتما. چه روزی خوبه دوباره پیام بدم؟» (ثبت کن.) |
| «پیام نده» | «حتما، حذف شد. سپاسگزارم.» و دیگه پیام نده. |

## ۶) پیام خوش‌آمد بعد از تأیید همکاری (ربات خودش می‌فرستد؛ این نسخهٔ دستی برای تماس اول است)
```
درود 🌿 همکاریتون تایید شد. قدم‌های شروع:
۱. از ربات «پنل همکار» رو باز کنید.
۲. یه شارژ کوچیک به کیف پول بزنید و اولین سرویس رو بسازید.
۳. «گزارش من» و «مشتری‌های من» رو ببینید.
هر سوالی بود با «پشتیبانی ویژه» بنویسید؛ با اولویت جواب داده میشه. سپاسگزارم.
```

## ۷) چیزهایی که رقیب میگه و ما **نمیگیم** (و چرا)
| رقیب | چرا نمیگیم |
|---|---|
| «تحویل ۵ دقیقه‌ای» | تأیید درخواست دستی است؛ بعد از تأیید فوری فعال میشه. بگو «بعد از تأیید، همون لحظه». |
| «بدون محدودیت زمان / کاربر» | قولی که الان نمی‌توانیم ثابت کنیم. |
| «پشتیبانی تا پایان حجم» | تعهد نامشخص. |
| «پرداخت فقط هزینهٔ حجم مصرف‌شده» | مدل ما شارژ کیف پول است، نه پرداخت بعد از مصرف. |
| «۶ لوکیشن» | لوکیشن‌ها را با اسم و درست بگو (آمریکا، آلمان، هلند، لهستان، فنلاند). |
